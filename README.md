# RDP Manager

轻量级远程桌面（`.rdp`）连接管理工具。

## 启动主密码与自动锁定

- **首次设置**：首次启动时会提示设置启动主密码（也可选择“暂不启用”，后续在顶栏点击 **主密码** 随时开启）。
- **启动锁定**：启用后，每次打开应用需输入主密码解锁；主密码使用随机盐 + PBKDF2-HMAC-SHA256（100,000 次迭代）保存于数据目录的 `master.json`，不保存明文。
- **自动锁定**：已解锁状态下 **10 分钟无操作** 将自动锁回到输入主密码界面；也可随时点击顶栏 **锁定** 按钮手动锁定，或在 **主密码** 弹窗中修改/关闭主密码。

## 系统托盘与退出确认

- **缩小到托盘图标**：点击窗口最小化按钮后，程序会隐藏到 Windows 系统托盘小图标；左键点击托盘图标或右键选择 **打开主窗口** 可恢复显示。
- **退出确认**：点击主窗口右上角关闭按钮会弹出“确认退出”对话框；右键托盘图标选择 **退出** 可直接退出程序。

## 免密登录说明（Windows 组策略配置）

本工具通过 Windows `cmdkey` 将账号密码写入系统凭据管理器（`TERMSRV/<主机>`），并在启动 `mstsc.exe` 时关闭凭据提示。

如果已在工具中保存了用户名和密码，但连接时 **Windows 仍弹窗要求输入密码**，通常是因为 Windows 默认禁止将已保存的凭据委托给仅使用 NTLM 身份验证的远程主机（如 IP 直连或非域环境主机）。

### 解决方法：启用凭据分配组策略

1. 按 `Win + R`，输入 `gpedit.msc` 并回车，打开**本地组策略编辑器**。
2. 依次展开路径：
   - **中文系统**：`计算机配置` → `管理模板` → `系统` → `凭据分配` → **允许分配保存的凭据用于仅 NTLM 服务器身份验证**
   - **英文系统**：`Computer Configuration` → `Administrative Templates` → `System` → `Credentials Delegation` → **Allow delegating saved credentials with NTLM-only server authentication**
3. 双击打开该策略，选择 **已启用（Enabled）**。
4. 点击下方的 **显示（Show...）** 按钮，在列表中填入：
   ```text
   TERMSRV/*
   ```
   点击 **确定** 保存并关闭组策略编辑器。
5. 以管理员身份打开 **命令提示符（CMD）** 或 **PowerShell**，执行以下命令使策略立即生效：
   ```cmd
   gpupdate /force
   ```
6. 看到“计算机策略更新成功完成”后，重新通过本工具发起连接即可。

### 补充说明

- **必须同时填写用户名和密码**：若只填密码未填用户名，不会触发自动凭据写入。
- **服务端/网关强制策略**：若目标服务器或企业 RD Gateway（远程桌面网关）在服务端强制开启了“始终在连接时提示输入密码”（或要求动态令牌/MFA），则任何客户端保存的密码都无法绕过，仍会弹窗提示输入。
